# Исправление: полный список подключений и строго ручной состав балансировщиков

## Обновление подключений

`/get-info-api/adm` → балансировщик → «Обновить список» запрашивает `/panel/api/inbounds/list`, сохраняет записи с корректным уникальным ID **без фильтра по протоколу** и показывает количество инбаундов, возвращённых панелью. Повторное обновление не стирает сохранённые назначения. Переименованные инбаунды сохраняют ID.

Это именно **все строки, возвращённые API 3x-ui**: если конкретная строка отсутствует даже в `/panel/api/inbounds/list`, браузер не может её обнаружить. Наличие инбаунда в списке не означает, что конкретный клиентский профиль существует и поддерживается Xray/Happ. В AUTO попадут только действительные профили из подписки и назначенных пулов.

## Строго ручные пулы

В `smart_routing.build_auto()` больше нет неявного расширения пула `all` за счёт `gemini` или `other`. Для любого балансировщика `selector` строится только по явно сохранённым галочкам `smart_nodes.pools`. Пересечения между пулами возможны **только при ручном назначении** одного и того же инбаунда в несколько пулов. Неназначенные узлы не включаются. Резервные узлы по-прежнему доступны только при `--rest`.

Веб-переключатель «Для остального трафика» и аналогичная кнопка Telegram скрыты. **Важно:** существующий выбор маршрута по умолчанию остаётся в базе и применяется генератором для трафика, не совпавшего с правилами; при миграции это обычно балансировщик «Все сайты». Это логика выбора маршрута, а не автоматического добавления серверов в балансировщик. Если на него не назначено ни одного узла, генератор использует другой активный основной пул согласно прежнему алгоритму.

Существующие таблицы SQLite, назначения, правила и другие настройки не изменяются и не очищаются. Старую базу сохраняйте, предварительно сделав её резервную копию.

## Установка и тесты

Замените файлы проекта, сохранив текущие `.env` и SQLite. Перезапустите Python-сервис и админ-бота, затем нажмите «Обновить список» и обновите подписку в Happ/Incy.

Проверка: `python -m unittest discover -s tests -q`. Проверено локально 59 тестов; живой API панели может возвращать другой список в зависимости от прав токена.
